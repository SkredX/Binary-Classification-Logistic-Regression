How to Run the Program in Jupyter Notebook

Requirements

-   Install Anaconda (recommended) or Python 3.x with Jupyter Notebook
    support.
-   Required libraries: pandas, numpy, matplotlib, scikit-learn (if used
    in the notebook).

Steps to Run

1.  Open Anaconda Navigator (or directly open terminal/command prompt).
2.  Launch Jupyter Notebook.
3.  Navigate to the folder where the file
    22BT30025-P2-ShuvamVidyarthy.ipynb is saved.
4.  Open the notebook file by clicking on it.
5.  Run each cell sequentially by pressing:
    -   Shift + Enter (to run a single cell and move to the next)
    -   or select Cell > Run All from the top menu to execute all cells
        at once.

Notes

-   Make sure all dependencies are installed. If any library is missing,
    install it using:

        pip install library_name

    or in Jupyter Notebook cell:

        !pip install library_name

-   If you face kernel errors, restart the notebook kernel from the
    menu: Kernel > Restart & Run All.
